# 公式ブランド画像の置き場所

ここに公式のロゴ・キャラクター画像（白背景の PNG / JPG）を置いて、
リポジトリのルートで次を実行してください:

```bash
npm run brand:transparent
```

背景だけが透過処理され、`public/brand/` に透過 PNG が出力されます。
`lib/brand.ts` のパスも自動で更新され、全画面に反映されます。

## ファイル名の規則

| 画像 | ファイル名（例） |
|------|------------------|
| ロゴ（横） | `logo.png` |
| マークのみ（任意） | `mark.png` |
| ライトくん | `light-kun.png` |

> 白背景の画像を想定しています。背景が白でない場合はご相談ください。
